# 🥑 Avocado DevOps — Business Finance Tracker

A clean, dark-themed business finance tracker for managing income, expenses, categories, and partner contributions.

## Features

- **Dashboard** — Income, expenses, net profit, fund balance at a glance
- **Transactions** — Full CRUD with filters, search, and date range
- **Categories** — Color-coded expense/income categories with budgets
- **Partners** — Track partner contributions and share breakdowns
- **Reports** — Interactive charts (Chart.js) for expense breakdown and monthly trends

## Tech Stack

- Single-file HTML/CSS/JS application
- Chart.js for data visualization
- Google Fonts (Fraunces, JetBrains Mono, Inter)
- Firebase integration for authentication & real-time sync

## Live Site

🔗 [GitHub Pages](https://obaidurrehman221.github.io/finance-tracker-/)

## Getting Started

1. Open `index.html` in a browser
2. Configure Firebase credentials for multi-user sync
3. Add your business name and start tracking!
